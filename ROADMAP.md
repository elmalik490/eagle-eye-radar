# Roadmap and Safe Next Steps

This roadmap records handover-safe next steps only. It does not authorize product development, outreach, data collection, or architecture changes.

## Immediate handover steps

1. Verify the documentation checkpoint commit on `main` and the GitHub Pages workflow result for that commit.
2. Have the receiving Manus account independently clone/open the GitHub repository and confirm the live URL.
3. If the private commercial-validation materials are needed, arrange access through an approved private channel. Do not move those materials into this public repository.
4. Keep the deployed v0.1 prototype unchanged until the project owner approves a new scope.

## Later decisions — only after explicit owner direction

- Decide whether Eagle Eye should remain a synthetic UI prototype or whether a separately scoped real-data product is desired.
- If any real-data work is authorized, define evidence sources, consent/privacy constraints, data handling, security, and acceptance criteria before implementation.
- Decide separately whether to continue private commercial validation. No prospect may be contacted until the exact outreach content and channel receive human approval.

## Not currently planned or authorized

No backend, API, SMS, voice, payment, real-data collection, 3D globe, redesign, or new feature is included in this checkpoint.
